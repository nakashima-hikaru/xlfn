# cargo-xlfn

Cargo subcommand for building, inspecting, validating, and packaging native Excel XLL add-ins.

Install it with:

```text
cargo install cargo-xlfn --locked
```

Then run commands such as:

```text
cargo xlfn check --target x86_64-pc-windows-msvc
cargo xlfn package --all
```

Documentation: [User guide](https://nakashima-hikaru.github.io/xlfn/) | [API docs](https://docs.rs/cargo-xlfn) | [crates.io](https://crates.io/crates/cargo-xlfn)
