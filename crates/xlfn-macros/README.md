# xlfn-macros

Procedural macros for declaring Excel add-ins, worksheet functions, handles, and related metadata in the `xlfn` framework.

> **API Policy**: `xlfn` is the only supported public API for add-in authors. `xlfn-macros` is an implementation crate and does not guarantee standalone semantic versioning stability. This crate is normally re-exported by [`xlfn`](https://crates.io/crates/xlfn); application crates should depend on `xlfn` directly instead of using this crate directly.
