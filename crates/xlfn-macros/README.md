# xlfn-macros

Procedural macros for declaring Excel add-ins, worksheet functions, handles, and related metadata in the `xlfn` framework.

This crate is normally re-exported by [`xlfn`](https://crates.io/crates/xlfn); application crates should generally depend on the facade instead of using this crate directly.

Documentation: [User guide](https://nakashima-hikaru.github.io/xlfn/) | [API docs](https://docs.rs/xlfn-macros) | [crates.io](https://crates.io/crates/xlfn-macros)
