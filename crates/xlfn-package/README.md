# xlfn-package

XLL bundle validation, PE inspection, dependency-closure checks, artifact staging, and transactional package preparation for `cargo-xlfn`.

This is the packaging support crate used by the [`cargo-xlfn`](https://crates.io/crates/cargo-xlfn) CLI. Direct use is intended for integrations that need to build or validate XLL packages programmatically.

Documentation: [User guide](https://nakashima-hikaru.github.io/xlfn/) | [API docs](https://docs.rs/xlfn-package) | [crates.io](https://crates.io/crates/xlfn-package)
