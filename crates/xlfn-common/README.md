# xlfn-common

Shared platform-independent validation rules used by the `xlfn` framework and its packaging tools.

This is a small support crate and is not normally needed directly by an Excel add-in.

Documentation: [User guide](https://nakashima-hikaru.github.io/xlfn/) | [API docs](https://docs.rs/xlfn-common) | [crates.io](https://crates.io/crates/xlfn-common)
