# xlfn-core

Core runtime layer for `xlfn`, providing Excel value handling, registration, lifecycle coordination, handles, diagnostics, caching, RTD, and asynchronous UDF support.

Most add-in projects should depend on the [`xlfn`](https://crates.io/crates/xlfn) facade crate instead. Use `xlfn-core` directly when building an integration that needs lower-level runtime control.

Documentation: [User guide](https://nakashima-hikaru.github.io/xlfn/) | [API docs](https://docs.rs/xlfn-core) | [crates.io](https://crates.io/crates/xlfn-core)
